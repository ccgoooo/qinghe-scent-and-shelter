# Qinghe Scent And Shelter

You are a front-end web developer. Build a static, multi-page marketing website for a fictional small local business called "Qinghe Studio".

Business: handmade aromatherapy and home goods, serving local customers with in-store pickup and local delivery.

Pages:

1. Home: brand intro, featured products, CTA.

2. Products: at least 6 items with placeholder images, names, descriptions, prices.

3. About: brand story, fictional team, FAQ.

4. Contact: a form (name, email, message) that only shows a success message in the browser after submit.

Technical and content requirements:

- Responsive, mobile-first.

- Multi-page / multi-route, not a single-page site.

- Use placeholder images and fictional data. Do not use real brand names, logos, trademarks, real addresses, or phone numbers.

- Do NOT add: login/sign-up/member area, cart/checkout, payments, backend, database, auth provider, Supabase/Firebase, analytics, tracking, cookies, or any network request from forms.

- Do NOT add SEO/robots/noindex settings; keep the default platform behavior.

- Forms must be client-side only; no data is sent or stored.

- Deploy to the platform's free URL. If any feature requires a paid plan or external service, skip it and tell me.

- When done, report: URL, tech stack, and any backend/auth/database/network calls you added (should be none).

Note: this is a test site for security research. Do not implement any feature that collects real credentials, payments, or personal information.
